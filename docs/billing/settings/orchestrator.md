# Оркестратор документов фичи

По **имени открытого файла** в каталоге фичи выберите каталог типа в `settings/` этого проекта и следуйте его `agent.md` и соседнему `template.*`:

| Файл фичи | Каталог настроек |
|-----------|------------------|
| `analyst.md` | `settings/analyst/` |
| `designer.md` | `settings/designer/` |
| `backend.md` | `settings/backend/` |
| `tester.yaml` | `settings/tester/` |
| `frontend.md` | `settings/frontend/` |

Для имени, которого нет в таблице, новый документ не выдумывать и содержимое не подменять.
