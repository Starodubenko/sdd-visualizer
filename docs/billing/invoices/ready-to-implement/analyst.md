# Реестр счетов

feature: invoices
role: analyst

## Контекст

Бухгалтер открывает реестр счетов из раздела «Биллинг», чтобы отметить, какие счета уже отправлены клиенту.

## Результат

Виден список счетов с номером, суммой, датой отправки и отметкой «Отправлен» или «Черновик». Отметить счёт отправленным можно одной кнопкой в строке.

## Критерии приёмки

- AC-1. В реестре видны номер, сумма и отметка черновика или отправленного счёта.
- AC-2. Кнопка «Отметить отправленным» у черновика меняет отметку на «Отправлен».
- AC-3. Уже отправленный счёт не показывает эту кнопку.

## Вне задачи

- Печать счёта.
- Правка суммы.

## Контракт

- метод: GET
- путь: /invoices
- поля: number, amount, sent
