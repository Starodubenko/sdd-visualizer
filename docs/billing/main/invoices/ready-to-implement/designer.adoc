= Реестр счетов

feature: invoices
role: designer
depends: analyst.adoc
ui: screen

== Покрытие критериев

|===
| AC | Что пользователь видит или делает

| AC-1 | Колонки «Номер», «Сумма», «Отметка»
| AC-2 | Кнопка «Отметить отправленным» у черновика
| AC-3 | У отправленного счёта кнопки нет
|===

== Состояния

|===
| Состояние | Когда наступает | Что видит пользователь | Текст | Доступное имя

| Загрузка | идёт запрос реестра | скелет строк | Загрузка счетов | Реестр счетов загружается
| Пусто | счетов нет | сообщение | Счетов нет | Реестр счетов пуст
| Ошибка | запрос не удался | сообщение и повтор | Не удалось загрузить счета | Ошибка реестра счетов
| Нет прав | нет права биллинга | сообщение | Недостаточно прав | Нет доступа к счетам
| Валидация | не наступает |  |  | 
| Успех | список получен | таблица и кнопки у черновиков |  | Реестр счетов
|===

== Тексты

|===
| Место | Текст из интерфейса

| Черновик | Черновик
| Отправлен | Отправлен
| Кнопка | Отметить отправленным
| Пусто | Счетов нет
|===
