= Оплата заказа

feature: order-payment
role: analyst

== Контекст

Оператор открывает форму оплаты заказа. На форме список заказов из фичи order-list, и с неё заказ оплачивают.

== Результат

На форме виден список заказов. Заказ из этого списка можно оплатить с формы.

== Критерии приёмки

* AC-1. На форме виден список заказов.
* AC-2. Заказ из списка можно оплатить с этой формы.

== Вне задачи

* Карточка платежа.
* Правка заказа, кроме оплаты с этой формы.

== Контракт

* метод: GET
* путь: /orders
* поля: number, amount, status
