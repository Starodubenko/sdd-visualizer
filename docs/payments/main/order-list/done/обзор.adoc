= Обзор дня для оператора

Короткий разбор, который аналитик прикладывает к списку заказов. Это не ключевой артефакт роли, а заметка рядом со спецификацией.

== Что проверяем глазами

. За текущий день таблица не пустая на стенде с демо-заказами.
. Сумма показана с двумя знаками и валютой.
. Статус читается без кода: «Новый», «Оплачен», «Отменён».
