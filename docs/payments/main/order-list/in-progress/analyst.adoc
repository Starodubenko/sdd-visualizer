= Список заказов

feature: order-list
role: analyst

== Контекст

Оператор платёжного контура открывает список заказов из бокового меню «Платежи». На экране он сверяет номер, сумму и статус перед тем, как перейти в карточку.

== Результат

На экране видна таблица заказов за выбранный день. Пустой день показывает текст «Заказов нет», ошибка загрузки показывает «Не удалось загрузить заказы» и кнопку повтора.

== Критерии приёмки

* AC-1. После открытия страницы видна таблица с колонками «Номер», «Сумма», «Статус».
* AC-2. Если за день заказов нет, вместо таблицы виден текст «Заказов нет».
* AC-3. Если загрузка не удалась, виден текст ошибки и кнопка «Повторить».

== Вне задачи

* Редактирование заказа из списка.
* Выгрузка в файл.
* Фильтр по магазину.

== Контракт

* метод: GET
* путь: /orders
* поля: number, amount, status

== Схема

[source,mermaid]
----
sequenceDiagram
  actor Operator as Оператор
  participant Page as Список заказов
  participant API as GET /orders

  Operator->>Page: открывает меню «Платежи»
  Page->>API: day выбранного дня
  alt есть заказы
    API-->>Page: number, amount, status
    Page-->>Operator: таблица «Номер», «Сумма», «Статус»
  else заказов нет
    API-->>Page: пустой список
    Page-->>Operator: «Заказов нет»
  else загрузка не удалась
    API-->>Page: ошибка
    Page-->>Operator: «Не удалось загрузить заказы» и кнопка «Повторить»
    Operator->>Page: «Повторить»
    Page->>API: тот же day
  end
----
