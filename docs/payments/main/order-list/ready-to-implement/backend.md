# Список заказов

feature: order-list
role: backend
depends:
  - analyst.md
  - designer.md

## Операция

- метод: GET
- путь: /orders

## Запрос

| Поле | Тип | Обязательность | AC |
|------|-----|----------------|----|
| day | date | да | AC-1 |

## Пример запроса

```json
{
  "day": "2026-10-21"
}
```

## Ответ

| Поле | Тип | AC |
|------|-----|----|
| number | string | AC-1 |
| amount | string | AC-1 |
| status | string | AC-1 |

## Пример ответа

```json
[
  {
    "number": "ORD-1042",
    "amount": "1500.00",
    "status": "paid"
  },
  {
    "number": "ORD-1043",
    "amount": "320.50",
    "status": "pending"
  }
]
```

## Ошибки

| HTTP | Код | Состояние из designer.md | Когда |
|------|-----|--------------------------|-------|
| 500 | orders_unavailable | Ошибка | хранилище не ответило |
| 403 | forbidden | Нет прав | у оператора нет права читать заказы |

Пустой день — это `200` и пустой массив, не ошибка.

## Правила сервера

- `day` обязателен и должен быть датой.
- Повтор того же запроса возвращает тот же набор строк.

## Эффекты

- Строки заказов не создаются и не меняются.

## Данные

| Таблица PostgreSQL | Сущность TypeORM | Миграция |
|--------------------|------------------|----------|
| нет | нет | чтение существующей таблицы orders |
