= Карточка платежа

feature: payment-card
role: designer
depends: analyst.adoc
ui: screen

== Покрытие критериев

|===
| AC | Что пользователь видит или делает

| AC-1 | Номер, сумма и получатель
| AC-2 | Причина отказа под статусом «Отклонён»
| AC-3 | Текст «Платёж не найден»
|===

== Состояния

|===
| Состояние | Когда наступает | Что видит пользователь | Текст | Доступное имя

| Загрузка | идёт запрос карточки | три пустые строки | Загрузка платежа | Карточка платежа загружается
| Пусто | не наступает |  |  | 
| Ошибка | сервис недоступен | сообщение | Не удалось открыть платёж | Ошибка карточки платежа
| Нет прав | нет права чтения | сообщение | Недостаточно прав | Нет доступа к платежу
| Валидация | номер пустой | сообщение у поля | Укажите номер платежа | Номер платежа
| Успех | карточка найдена | сумма, получатель, статус | Проведён | Карточка платежа
|===

== Тексты

|===
| Место | Текст из интерфейса

| Статус успеха | Проведён
| Статус отказа | Отклонён
| Не найден | Платёж не найден
| Ошибка | Не удалось открыть платёж
|===
