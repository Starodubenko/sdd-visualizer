next: done

## Do

- Справа от селектора «Проект» добавить поле с подписью «Фича» и список «Статус».
- Поле фильтрует на каждом изменении текста. Совпадение — подстрока имени фичи без учёта регистра. Пробелы по краям не участвуют в сравнении.
- Список статуса: «Все» и четыре подписи из `statusLabel`. «Все» показывает фичи любого статуса.
- В дереве скрывать фичу, если имя или статус не совпали. В карточке проекта скрывать те же фичи. Внутри фичи список файлов не менять.
- Чистая функция совпадения покрыта тестом в `tree-window.test.ts`.
- Если после фильтра фич не осталось, а без фильтра они были, в дереве показать «Ничего не найдено».

## Do not

- Не менять сервер и фикстуры.
- Не закрывать открытый документ, когда его фича скрыта фильтром.
- Не фильтровать файлы внутри фичи по этому имени или статусу.

- `npm test -w @sdd/web` проходит.
- `npm run build -w @sdd/web` проходит.
