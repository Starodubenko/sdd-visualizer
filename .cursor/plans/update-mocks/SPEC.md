# Моки изменений

У фичи `billing/invoices` два файла в `updates`. Исходные спеки не меняются.

Открытое изменение отличается от снимка: это кейс «требуется изменение». Закрытое изменение уже совпадает с текущей секцией исходника: это кейс «выполнено».

```text
docs/billing/invoices/updates/
  in-progress/2026-10-21-1405-analyst-rezultat.md
  done/2026-10-20-0910-analyst-vne-zadachi.md
```
