next: 02

- `.cursor/plans/open-change-column/state.md`

## Do

- У записи файла в списке фичи появляется `hasOpenChange: true`, если в `updates/in-progress` есть файл, у которого `source` совпадает с именем этого файла.
- Поле `status` остаётся статусом каталога: `in_progress`, `ready` или `done`.
- Файл без такого `source` и каталоги вроде `updates` поле не получают.
- Тест на копии фикстур: в списке `docs/billing/invoices` у `analyst.md` статус `ready` и `hasOpenChange: true`, у `backend.md` признака нет. После переноса `updates/in-progress/2026-10-21-1405-analyst-rezultat.md` в `done` у `analyst.md` признака нет.

## Do not

- Не менять `apps/web` и фикстуры.
- Не подменять `status` значением `changes`.
- Не менять расчёт статуса фичи.

## Done when

- `npm test -w @sdd/server` проходит.
- `npm run build -w @sdd/server` проходит.
