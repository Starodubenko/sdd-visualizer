## Do

- `POST /api/settings/agents` с телом `{ name }` создаёт каталог и два файла из SPEC и дописывает строку таблицы в `docs/settings/orchestrator.md`.
- Повторное имя — `BadRequestException` «Агент уже существует». Имя не kebab-case — «Имя агента — kebab-case». Нет файла оркестратора — «Нет оркестратора». В этих случаях каталог не появляется.
- `DELETE /api/settings/agents?name=` удаляет каталог `docs/settings/<name>` и строку таблицы, во второй ячейке которой путь `docs/settings/<name>/`. Нет такого каталога — `NotFoundException` «Агент не найден».
- Тексты `template.md` и `agent.md` — как в SPEC, не копировать шаблон аналитика.
- Тесты на копиях фикстур: новый агент `review` даёт оба файла и строку; повтор не меняет оркестратор; пустое имя отклоняется; удаление `review` убирает каталог и строку, строка `analyst.md` остаётся.

## Do not

- Не менять `apps/web`.
- Не менять уже лежащие шаблоны analyst, designer, backend, tester, frontend.
- Не удалять `orchestrator.md`.

## Done when

- `npm test --workspace @sdd/server` проходит.
