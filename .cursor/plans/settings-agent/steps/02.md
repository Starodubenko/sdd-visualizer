# 02 Кнопки на экране настроек

role: developer
next: done

## Read

- `.cursor/plans/settings-agent/SPEC.md`
- `.cursor/plans/settings-agent/state.md`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — бургер настроек, `DirectoryPane`, модал «Добавить фичу»
- `apps/web/src/shared/api.ts`
- `apps/server/src/documents/documents.controller.ts` — маршруты из шага 01

## Do

- В бургере `/settings` под «Документация» пункт «Добавить Агента». Окно как у новой фичи: поле «Имя (kebab-case)», «Отмена» и «Создать». Ошибка сервера остаётся текстом в окне.
- После успеха закрыть окно, обновить дерево `docs/settings` и открыть новый каталог.
- У каталога, чей путь `docs/settings/<имя>` и это ровно один сегмент под settings, в шапке имя и кнопка «Удалить». Подтверждение «Удалить агента?». После успеха открыть корень `docs/settings`.
- На корне настроек и на файле кнопки «Удалить» нет.

## Do not

- Не показывать «Добавить Агента» в бургере рабочего экрана фич.
- Не вешать удаление на фичи проектов.
- Не менять сервер.

## Done when

- `npm test --workspace @sdd/web` проходит.
- `npm run build --workspace @sdd/web` проходит.
