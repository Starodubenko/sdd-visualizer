# 02 Экран теории и пункт бургера

role: developer
next: done

## Read

- `.cursor/plans/method-route/SPEC.md`
- `.cursor/plans/method-route/state.md`
- `.cursor/plans/method-route/steps/01.md`
- `apps/server/src/ssr/ssr.service.ts` — форма `page: 'method'`
- `apps/web/src/shared/api.ts` — `PageData`
- `apps/web/src/App.tsx`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — шапка, бургер, дерево, адресная строка

## Do

- Клиентский `PageData` повторяет `page: 'method'`. `App` открывает `WorkspacePage` с `mode: 'method'`.
- Экран — тот же каркас: дерево слева от `docs/method`, справа каталог или документ. Адрес `/method` с `path` и `open`, как у настроек. Назад и вперёд остаются на `/method`.
- Заголовок «Визуализатор: Теория». Нет селектора проекта, фильтров эпика, фичи и статуса, синхронизации. Меню изменений и тема остаются.
- Бургер рабочего экрана и экрана настроек: пункт «Теория» ведёт на `/method`. Бургер теории: «Документация» на `/` и «Настройки» на `/settings`. Переход — обычная ссылка.
- События файлов под `docs/method/` обновляют открытый экран.

## Do not

- Не добавлять на теории создание эпика, фичи, агента и ссылки на документацию.
- Не менять маршрут `/settings`.
- Не показывать `method` в селекторе проектов.

## Done when

- `npm test --workspace @sdd/web` проходит.
- `npm run build --workspace @sdd/web` и `npm run build --workspace @sdd/server` проходят.
- В браузере `/` открывает бургер с пунктом «Теория», `/method` показывает файлы `docs/method`, документ теории открывается, «Документация» возвращает на `/`.
