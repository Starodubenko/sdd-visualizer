# 01 Создание файла изменения

role: developer
next: 02

## Read

- `.cursor/plans/collapser-updates/SPEC.md`
- `apps/server/src/documents/documents.service.ts`
- `apps/server/src/documents/documents.controller.ts`
- `apps/server/src/documents/documents.service.test.ts`

## Do

- `POST /api/updates` с телом `{ path, section, body }` создаёт файл `docs/<проект>/<фича>/updates/in-progress/YYYY-MM-DD-HHMM-<имя-без-расширения>-<секция>.md`.
- Время для имени передаётся в сервис аргументом, чтобы тест был стабильным. Контроллер вызывает без своего времени.
- Содержимое:

```md
source: <имя файла>
section: <заголовок>

## Оригинал

<body>

## Правка

<body>
```

- Каталог создаётся при записи. Если файл с таким именем уже есть, добавить суффикс `-2`.
- Пустая секция или путь не из каталога статуса фичи — ошибка 400.
- Тест на фикстуре invoices: путь, `source: analyst.md`, секция «Результат», оба блока с переданным текстом.

## Do not

- Не менять клиент и фикстуры.
- Не писать в исходный файл спеки.

## Done when

- `npm test -w @sdd/server` проходит, включая новый тест.
- `npm run build -w @sdd/server` проходит.
