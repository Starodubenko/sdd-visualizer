## Do

- `GET /settings` отдаёт ту же SSR-страницу. `PageData` различает `page: 'workspace'` и `page: 'settings'`. Для настроек начальные записи — список `docs/settings`.
- Экран настроек — тот же каркас, что у фич: дерево слева от `docs/settings`, справа каталог или документ. Файлы открываются и сохраняются существующим просмотром документа.
- На этом экране нет селектора проекта, фильтра фич, синхронизации и «Добавить фичу». Меню изменений остаётся.
- В бургере рабочего экрана пункт «Настройки» ведёт на `/settings`. В бургере настроек пункт «Документация» ведёт на `/`. Переход — обычная ссылка, полная загрузка страницы.
- Тумблер темы остаётся первым рядом бургера на обоих экранах.

## Do not

- Не показывать `settings` в селекторе проектов.
- Не делать для каталогов типов действия «Редактировать» и «Удалить» фичи.
- Не добавлять отдельный редактор документов.

## Done when

- `npm test --workspace @sdd/web` проходит.
- `npm run build --workspace @sdd/web` и `npm run build --workspace @sdd/server` проходят.
