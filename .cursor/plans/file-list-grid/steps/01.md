# 01 Сетка списка

role: developer
next: done

## Read

- `.cursor/plans/file-list-grid/SPEC.md`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — `DirectoryPane`
- `apps/web/src/style.css` — `.pane ul`, `.status-tag`, кнопки

## Do

- У списка в `DirectoryPane` класс, который задаёт сетку из двух колонок.
- Каждая строка делит эти колонки (`subgrid`), чтобы кнопки имён были одной ширины, а метки статуса стояли в одной вертикали.
- Колонки по содержимому, не на всю ширину карточки. Зазор между колонками 16px, между строками 8px. Кнопка имени выравнивает текст влево и заполняет свою ячейку.
- Строка без статуса остаётся только в первой колонке.

## Do not

- Не менять дерево, сервер и цвета меток.

## Done when

- В карточке фичи имена и метки «Готово к реализации» выровнены по двум колонкам.
- `npm test -w @sdd/web` проходит.
