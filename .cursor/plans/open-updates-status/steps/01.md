## Do

- Статус фичи принимает значение `changes`, если в `updates/in-progress` есть хотя бы один файл. Это выше `in_progress`, `ready` и `done`.
- `changes` только у каталога фичи в `list` и `describe`. У файлов статус остаётся `in_progress` | `ready` | `done`.
- В `docs/method/05-docs-repo.md` в том же абзаце про статус фичи дописать: незакрытый файл в `updates/in-progress` даёт фиче «Требуется изменение» и перекрывает три остальных статуса.
- Тесты на копии фикстур: `docs/billing/invoices` в `describe` и в списке `docs/billing` имеет `changes`, потому что там есть `updates/in-progress/2026-10-21-1405-analyst-rezultat.md`.
- Тест переноса ключевого файла из готово: сначала перенести этот файл изменения в `done`, затем перенести `frontend.md` в `in_progress` и ожидать `in_progress`.
- Тест «все ключевые в done»: пока файл изменения лежит в `updates/in-progress`, статус `changes`; после его переноса в `updates/done` и переноса всех ключевых в `done` статус `done`.

## Do not

- Не переносить файлы спеки в новый каталог.
- Не менять применение «Правка» и перенос файла изменения.
- Не менять фикстуры.
- Не трогать `apps/web`.

## Done when

- `npm test -w @sdd/server` проходит.
- `npm run build -w @sdd/server` проходит.
