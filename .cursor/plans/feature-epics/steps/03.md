## Do

- В бургере документации пункт «Добавить эпик». «Добавить фичу» из бургера убрать.
- Контент эпика: шапка с «Переименовать» и «Удалить», кнопка «Добавить фичу», у каждой фичи «Редактировать» и «Удалить». Подтверждение удаления эпика — «Удалить эпик?».
- В контенте фичи кнопок «Редактировать» и «Удалить» нет.
- В шапке документации перед «Фича» поле «Эпик». Фильтрация — как в SPEC, включая «Ничего не найдено».
- `resolveFeaturePath` возвращает `docs/<проект>/<эпик>/<фича>`. Путь без эпика — `null`.
- Тест на фильтр имени эпика и на `resolveFeaturePath` с эпиком.

## Do not

- Не менять страницу настроек и бургер настроек.
- Не менять сервер.
- Не показывать `settings` в дереве документации.

## Done when

- `npm test --workspace @sdd/web` проходит.
- `npm run build --workspace @sdd/web` проходит.
