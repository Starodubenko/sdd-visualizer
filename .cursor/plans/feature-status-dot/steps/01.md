# 01 Точка на строке фичи

role: developer
next: done

## Read

- `apps/server/src/documents/documents.service.ts` — `list`, `readFeatureStatus`
- `apps/server/src/documents/feature-status.ts`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — `TreeBranch`, точка `.tree-status` у файла

## Do

- В `list` проекта (каталог не является фичей) у дочернего каталога, внутри которого есть `in-progress` или `ready-to-implement`, проставить `status` из `readFeatureStatus`. Копировать запись, не мутировать кэш `listDirectory`.
- `assets` и другие каталоги без этих двух имён остаются без `status`.
- `TreeBranch` принимает необязательный `status`. На кнопке каталога имя и стрелка слева, точка справа теми же классами `tree-status`, `title` и `aria-label` через `statusLabel`.
- Тест: `list('docs/billing')` даёт `invoices` со `status: 'ready'`; `list('docs/payments')` даёт `order-list` со `status: 'in_progress'`. Список фичи не ставит `status` на `assets`.

## Do not

- Не менять правила готовности фичи и стили точки.
- Не ставить точку на корень проекта.

## Done when

- `npm test -w @sdd/server` и `npm test -w @sdd/web` зелёные.
