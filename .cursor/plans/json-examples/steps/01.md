# 01 Подсветка JSON

role: developer
next: 02

## Read

- `apps/web/src/features/document-view/MarkdownView.tsx`
- `apps/web/src/style.css` — `.markdown pre`

## Do

- `json-highlight.ts`: `formatJson` через `JSON.parse` и `JSON.stringify(..., 2)`, при ошибке `null`. `tokenizeJson` режет уже выровненный текст на `key`, `string`, `number`, `literal`, `punct`, `space`.
- В `MarkdownView` блок `language-json` рисуется токенами внутри `<code class="json">`. Ошибка разбора оставляет обычный `code`.
- Цвета только из токенов: ключ `--val`, строка `--ok`, число `--warn`, literal `--done`, пунктуация `--muted`.
- Тест: объект с ключом, строкой, числом и `true` даёт эти виды токенов; битый текст даёт `null`.

## Do not

- Не менять тексты спецификаций.
- Не подключать библиотеку подсветки.

## Done when

- `npm test -w @sdd/web` зелёный.
