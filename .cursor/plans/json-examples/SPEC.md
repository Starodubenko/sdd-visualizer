# Примеры JSON в спецификациях

В `backend.md` после таблиц запроса и ответа стоят секции «Пример запроса» и «Пример ответа». В каждой — один блок ` ```json ` с отступом в два пробела.

Визуализатор разбирает этот блок, выравнивает его и красит: ключи цветом `--val`, строки `--ok`, числа `--warn`, `true`/`false`/`null` цветом `--done`, скобки приглушённым `--muted`. Неразборный блок остаётся обычным кодом.
