# Точка «Внесены изменения» в дереве

У файла в дереве справа остаётся точка статуса каталога. Если у записи `hasOpenChange`, рядом с ней вторая точка цвета `--bad` с подсказкой «Внесены изменения».

Точки стоят вместе у правого края. У файла без незакрытого изменения вторая точка не рисуется. Точка фичи не меняется.
