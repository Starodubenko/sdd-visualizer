# 01 Вторая точка в строке файла

role: developer
next: done

## Read

- `.cursor/plans/tree-open-change-dot/SPEC.md`
- `.cursor/plans/tree-open-change-dot/state.md`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — кнопка файла в `TreeBranch`
- `apps/web/src/style.css` — `.tree-status`

## Do

- В строке файла дерева, если `entry.hasOpenChange`, справа от точки статуса каталога нарисовать точку `treeStatusClass('changes')`. Подсказка и `aria-label` — «Внесены изменения».
- Обе точки в одной группе у правого края, с зазором 6px. Одиночная точка каталога по-прежнему у правого края.
- У строки фичи ничего не менять.

## Do not

- Не менять сервер и фикстуры.
- Не заменять точку статуса каталога.
- Не рисовать вторую точку у каталога фичи.

## Done when

- `npm test -w @sdd/web` проходит.
- `npm run build -w @sdd/web` проходит.
