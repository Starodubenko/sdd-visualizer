## Do

- Удалить модуль проектов, контроллер, сервис и тесты. `global/configs.yaml` больше не источник адреса и токена.
- Убрать страницу `/admin` и сбор данных админки из SSR.
- Синхронизация и публикация берут удалённый репозиторий `origin` корня git. Корень git — ближайший вверх каталог с `.git` от `process.cwd()`.
- Нет `origin` — `BadRequestException` «У репозитория нет origin».
- Сохранить прежние отказы: грязное `docs/<проект>` и расхождение с `main`. Не вызывать merge, stash и reset --hard.
- Если workspace и корень git различаются, синхронизация записывает дерево `docs/<проект>` из `origin/main` в оба места, когда путь есть на origin. Публикация копирует `docs/<проект>` из workspace в корень git, коммитит и делает `git push origin HEAD`.
- Тесты публикуют и синхронизируют через `git remote add origin` на временный bare-репозиторий, без `ProjectsService`.
- В `README.md` убрать фразу про адрес и токен в `global/configs.yaml`.

## Do not

- Не менять `apps/web`, кроме того что сервер больше не отдаёт страницу админки.
- Не подставлять токен в URL.
