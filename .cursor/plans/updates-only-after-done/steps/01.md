# 01 Сервер принимает изменение только из done

role: developer
next: 02

## Read

- `.cursor/plans/updates-only-after-done/SPEC.md`
- `.cursor/plans/updates-only-after-done/state.md`
- `apps/server/src/documents/documents.service.ts` — `createUpdate`, `assertFeatureStatusFilePath`
- `apps/server/src/documents/documents.service.test.ts` — тест `createUpdate`
- `docs/method/05-docs-repo.md` — абзац про статус фичи и `updates`

## Do

- `createUpdate` отклоняет путь, в котором каталог статуса не `done`, с `BadRequestException`. Текст: «Изменение можно создать только для выполненного файла».
- `assertFeatureStatusFilePath` по-прежнему пускает три каталога статуса для остальных операций.
- Тест, который создаёт изменение из `ready-to-implement/analyst.md`, ожидает отказ и не создаёт файл. Отдельная проверка: после переноса этого `analyst.md` в `done` `createUpdate` пишет файл в `updates/in-progress` и не меняет спеку.
- В `docs/method/05-docs-repo.md` в абзац про `updates` добавить: файл изменения создаётся только для спеки из `done`.

## Do not

- Не менять `apps/web` и фикстуры.
- Не запрещать перенос ключевых файлов и «Выполнено» у файла изменения.

## Done when

- `npm test -w @sdd/server` проходит.
- `npm run build -w @sdd/server` проходит.
