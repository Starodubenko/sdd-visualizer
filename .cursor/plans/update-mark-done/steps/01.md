# 01 Выполнено для файла изменения

role: developer
next: done

## Read

- `.cursor/plans/update-mark-done/SPEC.md`
- `apps/server/src/documents/documents.service.ts` — `moveStatus`
- `apps/server/src/documents/documents.service.test.ts`
- `apps/web/src/features/document-view/DocumentView.tsx` — меню статуса
- `apps/server/test/fixtures/docs/billing/invoices/updates/in-progress/2026-10-21-1405-analyst-rezultat.md`

## Do

- Для документа внутри `/updates/`, который ещё не в `done`, меню «Действия» содержит только «Выполнено». Подтверждение уже есть.
- `moveStatus` для такого файла переносит его в `updates/done` той же фичи.
- Перед переносом подставляет тело «Правка» вместо секции `section` в файле `source`. Секция ищется как строка `## <section>` в markdown. Сравнение снимка «Оригинал» с текущим телом секции — по обрезанным краям. Если секция не найдена или текст разошёлся, вернуть 400 и не переносить файл.
- Тест на копии фикстур: перенос `docs/billing/invoices/updates/in-progress/2026-10-21-1405-analyst-rezultat.md` в `done` дописывает «датой отправки» в секцию «Результат» файла `analyst.md`, а исходный путь файла изменения больше не существует.

## Do not

- Не предлагать файлу изменения статусы «В процессе» и «Готово к реализации».
- Не менять правила переноса `analyst.md`, `designer.md`, `backend.md`, `tester.yaml`, `frontend.md`.
- Не менять фикстуры.

## Done when

- `npm test -w @sdd/server` и `npm test -w @sdd/web` проходят.
- `npm run build -w @sdd/server` проходит.
