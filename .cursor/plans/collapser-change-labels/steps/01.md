## Do

- Текст ссылки на применённое изменение: `Последние изменения` и дата `DD.MM.YYYY` через пробел. Клик по-прежнему открывает файл из `updates/done` на блоке «Правка».
- Если для секции есть файл в `updates/in-progress` с тем же `source` и `section`, кнопка называется «Текущие изменения» и открывает этот файл на блоке «Правка». Новый файл при этом не создаётся. Из нескольких таких файлов берётся самый поздний по префиксу в имени — та же функция, что выбирает последнее применённое изменение.
- Если незакрытого файла нет, кнопка остаётся «Добавить изменение» и создаёт файл как сейчас.
- То же для ключей YAML.

## Do not

- Не менять сервер, фикстуры и статус фичи.
- Не показывать эти подписи внутри файла из `/updates/`.
- Не убирать подсветку шапки незакрытого блока.
