# 01 Точка у правого края дерева

role: developer
next: done

## Read

- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — `TreeBranch`, строки файлов с `statusTagClass`
- `apps/web/src/style.css` — `.tree-row`, `.status-tag*`
- `apps/web/src/pages/Workspace/tree-window.ts` — `statusLabel`, `statusTagClass`

## Do

- В строке файла дерева (`TreeBranch`, `entry.kind !== 'dir'`) убрать текстовую метку `.status-tag`.
- Имя файла в отдельном `span`. После него, только если есть `entry.status`, круг 8×8 px.
- Класс точки: `tree-status tree-status-in-progress` или `tree-status tree-status-ready`.
- `margin-left: auto` прижимает точку к правому краю строки. Строка уже `display: flex`.
- `title` и `aria-label` точки — `statusLabel(entry.status)`.
- `statusLabel` и полные `.status-tag` в `DocumentView` и `DirectoryPane` не трогать.

## Do not

- Не менять сервер, пути статусов и цвета токенов.
- Не убирать текст статуса с карточки документа и из списка справа.

## Done when

- В дереве у файла видна только точка, прижатая вправо: янтарная для `in_progress`, зелёная для `ready`.
- Наведение показывает «В процессе» или «Готово к реализации».
- Справа от дерева полная метка статуса на месте.
