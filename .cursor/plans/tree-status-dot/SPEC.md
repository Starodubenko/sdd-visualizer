# Точка статуса в дереве

В колонке дерева статус файла — только цветная точка у правого края строки. Текст «В процессе» и «Готово к реализации» остаётся на карточке документа и в списке каталога справа.

Точка «В процессе» — `var(--warn)`. Точка «Готово к реализации» — `var(--ok)`. Подсказка при наведении и `aria-label` сохраняют русское название статуса.
