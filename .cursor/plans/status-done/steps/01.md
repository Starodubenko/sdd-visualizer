## Do

- Константа `DONE_DIR = 'done'`. `FileStatus` включает `'done'`. `statusDir('done')` возвращает `done`.
- `featureStatus` принимает имена из трёх каталогов. Статус ключевого файла: есть в `in-progress` → `in_progress`; иначе есть в `ready-to-implement` → `ready`; иначе есть в `done` → `done`; иначе `in_progress`. Статус фичи — наименее зрелый из пяти.
- `list` и `flattenFeatureListing` поднимают файлы из `done` со `status: 'done'` и не показывают каталог `done`. Каталог с любым из трёх имён — фича.
- `moveStatus` принимает текущий каталог `done` и перенос в него.
- В `docs/method/README.md`, `01-theory.md`, `02-maturity.md`, `03-transitions.md`, `04-roles.md`, `05-docs-repo.md` и в `.cursor/rules/00-project-context.mdc` путь статуса включает `done`. В `05-docs-repo.md` кратко описаны три каталога, три подписи и правило зрелости фичи.
- Фикстура: перенести `apps/server/test/fixtures/docs/payments/order-list/in-progress/обзор.md` в `.../done/обзор.md`.
- Тест: после переноса одного ключевого файла `invoices` в `done` фича остаётся `ready`. После переноса всех пяти — `done`. Список `order-list` содержит `обзор.md` со статусом `done` и не содержит каталог `done`.

- Не менять цвета и меню.
