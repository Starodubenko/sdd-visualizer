# 02 Кнопка сабагента

role: developer
next: done

## Read

- `.cursor/plans/settings-subagent/SPEC.md`
- `.cursor/plans/settings-subagent/state.md`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — шапка каталога агента, модал «Добавить Агента»
- `apps/web/src/shared/api.ts`
- `apps/server/src/documents/documents.controller.ts` — маршруты шага 01

## Do

- На каталоге `docs/settings/<агент>` рядом с «Удалить» кнопка «Добавить сабагента». Окно с полем «Имя (kebab-case)», «Отмена» и «Создать». Ошибка сервера видна в окне.
- После успеха закрыть окно, обновить дерево и открыть каталог сабагента.
- На каталоге `docs/settings/<агент>/<сабагент>` в шапке имя и «Удалить». Подтверждение «Удалить сабагента?». После успеха открыть каталог родителя.
- На корне настроек и на файле этих кнопок нет. «Добавить сабагента» не показывать в бургере.

## Do not

- Не менять сервер.
- Не вешать «Добавить сабагента» на фичи проектов и не подменять «Удалить фичу».

## Done when

- `npm test --workspace @sdd/web` проходит.
- `npm run build --workspace @sdd/web` проходит.
