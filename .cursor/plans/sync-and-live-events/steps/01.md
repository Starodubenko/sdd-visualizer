## Do

- `POST /api/sync` с телом `{ project }` синхронизирует только `docs/<project>` из `main` адреса проекта.
- `git fetch` по URL, без записи git config и без постоянного remote.
- Незакоммиченные изменения в `docs/<project>` — `BadRequestException` «Сначала опубликуйте локальные изменения», каталог не меняется.
- Если и локальные коммиты, и полученный `main` меняли `docs/<project>` — `BadRequestException` «Изменения разошлись с репозиторием», каталог не меняется. `git merge` не вызывать.
- Если вперёд ушёл только `main` — привести `docs/<project>` к этому дереву, включая удаления, затем `clearTreeCache()`.
- Нет адреса — «У проекта нет адреса репозитория».
- HTTPS-адрес с токеном собирается так же, как в публикации. Токен вырезается из текста ошибки.
- Ответ: `{ project, updated }`.
- Тесты на временных git-репозиториях: remote впереди и файл появляется; грязное дерево не меняется; расхождение не меняет локальный файл.

## Do not

- Не менять `apps/web`.
- Не менять поведение `publish`.
- Не делать `reset --hard` и не прятать конфликты через stash.

## Done when

- `npm test -w @sdd/server` проходит. Запуск с полными правами: `git init` в песочнице падает.
- `npm run build -w @sdd/server` проходит.
