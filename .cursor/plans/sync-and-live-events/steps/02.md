# 02 События об изменившихся файлах

role: developer
next: 03

## Read

- `.cursor/plans/sync-and-live-events/SPEC.md`
- `.cursor/plans/sync-and-live-events/state.md`
- `apps/server/src/documents/documents.controller.ts`
- `apps/server/src/documents/documents.module.ts`
- `apps/server/src/documents/tree.ts`

## Do

- `GET /api/events` отдаёт SSE.
- Наблюдение за каталогом `docs` внутри корня workspace. События из `.git` и `global` не уходят клиенту.
- Пачка изменений схлопывается примерно за 300 мс в одно событие со списком путей от корня workspace, вида `docs/<проект>/...`.
- Перед отправкой вызывается `clearTreeCache()`.
- Чистая функция отбора путей покрыта тестом: путь внутри `.git` и `global` отбрасывается, файл в `docs/<проект>` остаётся.

## Do not

- Не менять `apps/web` и синхронизацию из шага 01.
- Не подключать базу.

## Done when

- `npm test -w @sdd/server` проходит с полными правами.
- `npm run build -w @sdd/server` проходит.
