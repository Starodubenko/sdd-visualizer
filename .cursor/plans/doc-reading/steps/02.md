# 02 Ссылка на выделенный текст

role: developer
next: done

## Do

- `text-fragment.ts`:
  - `normalizeFragment(text)` схлопывает пробельные символы в один пробел и обрезает края.
  - `fragmentLink(fileName, text)` → ``[`label`](fileName#t=encodeURIComponent(normalized))``. Label — тот же текст, `]` и `[` заменены на пробел, длиннее 80 символов обрезан с `…`.
  - `fragmentFromHref(href)` достаёт `t` после `#`, иначе `null`. Путь до `#` остаётся целью файла.
- Кнопка «Скопировать ссылку» у выделения внутри `.sheet-card`. Пишет `fragmentLink` в буфер. Имя файла — последний сегмент текущего пути. Кнопка пропадает, когда выделение пустое.
- Ссылка с `#t=` открывает файл и передаёт текст подсветки. `openFile(path, highlight?: string | null)`. Клик из дерева передаёт `null`.
- После отрисовки документа найти первое совпадение нормализованного текста в `.sheet-card`, открыть родительский `details`, обернуть совпадение в `<mark class="text-hit">`, прокрутить `.sheet` так, чтобы метка была видна. Повторный заход без фрагмента снимает прежнюю метку.
- `.text-hit` — фон `var(--warn-soft)`, цвет `var(--ink)`.

## Do not

- Не писать ссылку в файл самому: только буфер обмена.
- Не менять секции и стили карточек из шага 01, кроме `.text-hit` и поповера.

## Done when

- Тест: `fragmentLink('analyst.md', 'виден список')` содержит `#t=` и имя файла.
- Клик по такой ссылке из другого документа открывает `analyst.md`, прокручивает к фразе и подсвечивает её.
