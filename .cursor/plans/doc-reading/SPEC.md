# Чтение markdown и yaml

Документ на карточке читается секциями. Секции шаблона сворачиваются. Имена соседних файлов открывают эти файлы. Выделение текста даёт ссылку: клик открывает файл, прокручивает к фрагменту и подсвечивает его.

## Секции

Markdown делится по строкам `## `. Текст до первого `## ` — шапка, без коллапсера. Каждый `## ` — блок `<details class="doc-block" open>` с заголовком в `<summary>`. Тело секции рендерится отдельно, картинки по-прежнему идут через `/api/raw`.

Yaml-объект делится по ключам верхнего уровня. `feature` и `role` остаются в шапке. Остальные ключи — такие же коллапсеры, открытые по умолчанию. `cases` — карточки, у каждой видны все строковые поля. Если yaml не разбирается, остаётся `<pre class="yaml">`.

## Ссылки на файлы

Кликабельны:

- markdown-ссылка с относительным путём на `.md`, `.yaml` или `.yml`;
- отдельное имя файла в тексте и в yaml (`analyst.md`, `tester.yaml`, в том числе имена не из латинских букв).

Внешние `http` и `https` открываются в новой вкладке. Клик по файлу не уходит со страницы: документ загружается в карточку. Если файла нет в текущем каталоге статуса, открывается тот же файл в другом каталоге статуса фичи.

## Ссылка на фрагмент

Выделение текста внутри карточки показывает кнопку «Скопировать ссылку». В буфер попадает markdown:

```text
[видимый текст](имя-файла.md#t=кодированный-текст)
```

`t` — выделенный текст, пробелы схлопнуты в один. Клик по такой ссылке открывает файл, раскрывает закрытую секцию, прокручивает `.sheet` к первому совпадению и оборачивает его в `<mark class="text-hit">`.
