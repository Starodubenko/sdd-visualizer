# 03 Фильтр проекта на странице настроек

role: developer
next: done

- `apps/web/src/App.tsx`

## Do

- `PageData` настроек содержит `projects` и `entries`. На `/settings` в шапке селектор «Проект», тот же, что на странице документации. Фильтры «Фича» и «Статус» и кнопка синхронизации скрыты.
- Дерево и чтение идут из `docs/<выбранный проект>/settings`. Смена проекта открывает этот корень и сбрасывает открытый файл.
- Агент — один сегмент под этим корнем, сабагент — два. `orchestrator.md` без кнопок агента. Создание, удаление и переименование передают выбранный проект.
- Кнопки шапки агента и сабагента остаются справа, «Удалить» с классом `danger`.
- Из меню изменений файл с путём `settings/...` на странице документации открывает `/settings?project=<проект>`. На странице настроек такой файл открывается в проекте изменения, без ухода на документацию.

## Do not

- Не менять сервер.
- Не показывать каталог `settings` в дереве фич на странице документации.
- Не менять действия фичи «Редактировать» и «Удалить».
