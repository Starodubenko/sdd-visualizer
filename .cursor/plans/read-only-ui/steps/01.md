# 01 Убрать запись из интерфейса

role: developer
next: done

## Read

- `apps/web/src/pages/Workspace/WorkspacePage.tsx`
- `apps/web/src/features/document-view/DocumentView.tsx`
- `apps/web/src/pages/Admin/AdminPage.tsx`
- `apps/web/src/shared/api.ts`

## Do

- Удалить из шапки меню «Действия» и модалки создания, удаления и публикации. Удалить состояние и функции `addFeature`, `removeFeature`, `publish`, `changeStatus`.
- В карточке документа убрать «Исходный текст», меню действий, смену статуса и «Добавить строку». Удалить `TaskForm.tsx`, если на него больше нет импортов.
- `DocumentView` больше не принимает `onContent` и `onStatus`.
- Из `api.ts` убрать неиспользуемые `saveDocument`, `moveDocument`, `createFeature`, `deleteFeature`, `publishProject`, `uploadAsset`, `saveProject`.
- Админка: без полей ввода, без «Сохранить» и без модалки. По выбранному проекту показать имя и адрес. Токен не показывать.

## Do not

- Не менять сервер и метод.
- Не убирать дерево, темы, секции и копирование ссылки на фрагмент.

## Done when

- В `apps/web/src` нет вызовов записи: PUT документа, POST статуса, POST/DELETE фичи, POST публикации, сохранение проекта.
- `npm test -w @sdd/web` зелёный.
