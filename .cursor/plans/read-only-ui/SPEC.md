# Только чтение

Интерфейс не меняет файлы. Новые тексты, статусы и состав фич попадают в дерево после коммита и пуша в репозиторий документации.

С экрана уходят: исходный текст и сохранение, смена статуса, строка задачи, создание и удаление фичи, публикация. Админка не принимает ввод и не пишет `configs.yaml`: видны имя проекта и адрес, токен не показывается.

Чтение остаётся: дерево, секции, ссылки на файлы и фрагменты, темы.
