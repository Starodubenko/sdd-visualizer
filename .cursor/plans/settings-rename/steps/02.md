# 02 Кнопки в контенте

role: developer
next: done

## Read

- `.cursor/plans/settings-rename/SPEC.md`
- `apps/web/src/pages/Workspace/WorkspacePage.tsx` — шапка каталога агента и сабагента, модал удаления
- `apps/web/src/shared/api.ts`
- `apps/server/src/documents/documents.controller.ts` — маршруты шага 01

## Do

- В контенте агента и сабагента показать «Переименовать» и «Удалить». Это и список каталога, и открытый файл внутри этого каталога. На корне настроек кнопок нет.
- Окно переименования: заголовок «Переименовать агента» или «Переименовать сабагента», поле с текущим именем, «Отмена» и «Переименовать». Ошибка сервера видна в окне.
- После успеха закрыть окно, обновить дерево и открыть каталог с новым именем. Открытый файл внутри перенесённого каталога открыть по новому пути.
- Удаление оставить с вопросами «Удалить агента?» и «Удалить сабагента?».
- У агента кнопка «Добавить сабагента» остаётся.

## Do not

- Не менять сервер.
- Не вешать эти кнопки на фичи проектов и не менять текст «Удалить фичу?».

## Done when

- `npm test --workspace @sdd/web` проходит.
- `npm run build --workspace @sdd/web` проходит.
